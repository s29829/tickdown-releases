# TickDown ⏱

Odliczanie czasu na Maca – wiele liczników naraz: do godziny, minutnik, godziny pracy, tydzień i weekend,
święta i pory roku, leki z alarmem, listy zadań i zakupów. Pasek menu, ikona w Docku na żywo, okno mini na wierzchu.

*Countdown timers for Mac – many at once: until a time, timer, work hours, week and weekend, holidays,
medication with alarm, to-do and shopping lists.*

### macOS – pierwsze uruchomienie / first launch
Aplikacja nie jest jeszcze podpisana certyfikatem Apple. W Aplikacjach kliknij TickDown **prawym przyciskiem → Otwórz**
(macOS 15+: Ustawienia → Prywatność i ochrona → *Otwórz mimo to*). Komunikat „uszkodzona”: `xattr -cr /Applications/TickDown.app`
