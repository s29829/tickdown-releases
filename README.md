# TickDown ⏱

Odliczanie czasu – wiele liczników naraz: do godziny, minutnik, godziny pracy, tydzień i weekend,
święta i pory roku, leki z alarmem, listy zadań i zakupów. Pasek menu, ikona w Docku na żywo, okno mini na wierzchu.

**Strona:** https://s29829.github.io/tickdown-releases/

## Pobieranie
Najnowsza wersja: **[Releases → Latest](https://github.com/s29829/tickdown-releases/releases/latest)**

| System | Plik |
|---|---|
| macOS 11+ | `.dmg` (albo `.app.zip`) |
| Windows 10/11 | `-setup.exe` albo `.msi` |
| Linux | `.AppImage`, `.deb`, `.rpm` |

Sumy kontrolne: `SHA256SUMS.txt` w każdym wydaniu.

### macOS – pierwsze uruchomienie
Aplikacja nie jest jeszcze podpisana certyfikatem Apple. Kliknij ją w Aplikacjach **prawym przyciskiem → Otwórz**
(macOS 15+: Ustawienia → Prywatność i ochrona → *Otwórz mimo to*). Komunikat „uszkodzona”:
`xattr -cr /Applications/TickDown.app`
